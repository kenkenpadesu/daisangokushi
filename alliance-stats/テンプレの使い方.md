# CSVテンプレの使い方

このフォルダには2つのテンプレCSVがあります。どちらも文字コードは **UTF-8（BOM付き）** です。

- `template_weekly.csv` … 毎週の武勲・勢力値データ用（列：名前 / 武勲 / 勢力値）
- `template_squads.csv` … 分隊分け用（列：名前 / 分隊）

## 基本の使い方（推奨）

1. AIチャットにゲームのスクショを渡し、テンプレと同じ列の並びで結果を出してもらう
2. その結果を、ダッシュボードの管理用URL（`?alliance=...&key=...`）を開いて表示される
   管理パネルの「貼り付け欄」にそのまま貼る
3. プレビューで確認・修正して「反映する」

この方法なら文字コードを一切気にする必要がありません（いちばんトラブりません）。

## CSVファイルとして使う場合

テンプレの列の並びを変えずに、2行目以降を自分のデータに置き換えてください。

- 1行目の見出し（名前,武勲,勢力値 など）は消さないでください。
- 数値にカンマは入れないでください（例：580,000 ではなく 580000）。
- 「万」表記は数字に直してください（例：58万 → 580000）。

### 注意：Excelで編集するとき
ExcelでこのCSVを開いて**保存し直すと、環境によっては文字コードが変わり、
アップロード時に日本語が文字化けする**ことがあります。

これを避けるには、保存のときに必ず
「**CSV UTF-8（コンマ区切り）(.csv)**」形式を選んでください。
通常の「CSV（コンマ区切り）」を選ぶと文字化けの原因になります。

不安な場合は、CSVファイルを使わず「貼り付け欄」に貼る方法をおすすめします。

## 分隊分けについて
分隊分けは「送るたびに、前回の分隊分けを全部置き換える」方式です。
分隊が変わった人だけでなく、**毎回全員分**を入れてください。
（過去の週の集計も、つねに最新の分隊で計算されます）
